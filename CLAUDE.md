## Design System Guidelines (My Application)
- The project design system is defined in `DESIGN.md` adhering to Material Design 3 (M3).

- Enforce sentence-case labels on buttons, tabs, and headers.
- Verify generated screens by running: `npm run tds -- evaluate <filepath> --strict` (must achieve 100/100 certified compliant before finalizing).
