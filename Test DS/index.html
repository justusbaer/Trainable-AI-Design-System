Guidelines & Executable Constraints

The foundational design thesis and strict rules enforced by Trainable DS for Porsche UI generation.

The Porsche Design Philosophy

  • Frosted Glass Depth: Uses backdrop-filter: blur(32px) with alpha overlays (--p-color-frosted-*) instead of artificial drop shadow layers.
  • Extreme Contrast: Anchored in pure Porsche black (#010205) and crisp white (#ffffff), maintaining minimum 4.5:1 text contrast.
  • 8px Quantum Rhythm: All paddings, margins, and layout gaps adhere strictly to multiples of 4px/8px.
  • Fluid Responsiveness: Fluid clamps eliminate viewport layout jumps.

Mandatory Executable Constraints

Rule ID Severity Requirement Remediation Fix
TDS-RAW-COLOR CRITICAL Zero raw hex codes (e.g. #010205) in inline styles or classes. Use var(--p-color-primary) or semantic tokens.
TDS-NON-QUANTUM-SPACING HIGH No arbitrary pixel spacing (e.g. padding: 13px). Use 8px increments (var(--p-spacing-static-md)).
TDS-REINVENTED-COMPONENT HIGH Never use raw HTML <button> or <input>. Use certified <p-button> and <p-input-search>.
TDS-TOUCH-TARGET-TOO-SMALL HIGH Every clickable element must be ≥ 48x48px. Enforce min-height: 48px; min-width: 48px;.
TDS-CAPITALIZATION-NOT-SENTENCE-CASE MEDIUM All button labels and titles must use sentence case. Write Discover models instead of Discover Models.
TDS-OFFICIAL-BRAND-ASSETS CRITICAL Never recreate Porsche logos or model scripts via text. Use <p-wordmark> and <p-model-signature>.
