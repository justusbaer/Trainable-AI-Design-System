One-Prompt Website Harvester

Zero-Touch Website Extraction

You do not need to know the crawling, font harvesting, or alignment process. Simply give your agent this prompt:
"Use Trainable Design System to extract the design system from <website url>"

1
Multi-Page Discovery

The agent automatically discovers /sitemap.xml and navigation links, classifying internal subpages into UX archetypes (home, listing, detail, form, content) to capture the full breadth of the system.

2
Deep Font & Icon Harvesting

Captures origin typography by extracting @font-face CDN .woff2 URLs into fonts.json, and pierces Web Component Shadow DOMs (like <ds-icon>) to extract vector SVGs into icons.json.

3
Iterative Alignment Loops (≥95%)

Executes autonomous visual alignment feedback loops comparing live computed styles against design tokens. Automatically patches discrepancies until cross-page compliance meets or exceeds 95%.

4
Component Library & Review Studio

Synthesizes executable React/TSX components in components/ui/*.tsx (100% compliant). Launches overview.html with the Component Review Studio where humans can test live previews, edit TSX code, bind to upstream packages (@mui/material, @radix-ui, shadcn/ui), and toggle 🔒 Lock to protect from crawler overwrites.

5
JIT Agent Querying (tds doc)

AI agents and engineers query certified imports, prop contracts, touch target rules, and copy-paste snippets on demand via tds doc <Component> or MCP tool get_component_code without bloating agent context windows (Meta Astryx parity).

Multi-Modal & DS-VCS Architecture

Multi-Modal Ingestion & Git-Native Version Control

Build and refine design systems from any source — images, app screenshots, brand guideline documents, CSV token sheets, or conversational AI prompts. Experiment safely on isolated branches and merge with AST-aware 3-way semantic reconciliation and automated accessibility gates.

1
Universal Ingestion Adapters

Accepts CSV/TSV tables, Figma Tokens Studio JSON, Markdown brand guidelines (DOs/DONTs), SVG/app screenshots (OKLab clustering & spatial quantum snapping), and natural language prompt directives.

tds ingest -f tokens.csv -t table
tds ingest -f guidelines.md -t document
2
Conversational AI Refinement

Refine tokens, component geometry, and accessibility rules in plain natural language. Directives like "Make primary button darker navy #002b66 and increase card radius to 12px" compile directly into exact patches.

tds refine "Change primary to #00458C"
3
Isolated Git-Native Branches

Branching engine stored in .tds/vcs/. Create experiments, dark-mode variations, or customer-specific sub-brands without polluting the main design system until reviewed and certified.

tds branch create feature/dark-mode
tds branch switch feature/dark-mode
4
AST 3-Way Merge & Evaluator Gate

AST-aware 3-way semantic merger automatically reconciles non-conflicting tokens and component props. Before merging into main, the Evaluator CI Gatekeeper verifies WCAG 2.1 AA contrast (≥4.5:1) and touch targets (≥48px).

tds merge feature/dark-mode --target main
